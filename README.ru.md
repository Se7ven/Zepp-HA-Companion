# Zepp HA Companion

[![Build](https://github.com/Se7ven/Zepp-HA-Companion/actions/workflows/build.yml/badge.svg)](https://github.com/Se7ven/Zepp-HA-Companion/actions/workflows/build.yml)

[English](README.md) | [Русский](README.ru.md) | [Polski](README.pl.md)

Приложение-компаньон для интеграции [Home Assistant](https://www.home-assistant.io/)
с умными часами **Amazfit** на базе **Zepp OS**.

- Целевое устройство: **Amazfit Balance 3** (480x480, Zepp OS 5/6, API_LEVEL до 4.4)
- Архитектура: мини-приложение Zepp OS (страницы на часах + app-side сервис с сетью через телефон)
- Подключение к Home Assistant: REST API + Long-Lived Access Token

## Возможности

- **Главный экран (хаб)** — включённые в настройках локации Home Assistant; каждая открывает
  список сущностей, сгруппированный по типам (свет, переключатели, сцены, скрипты,
  автоматизации и т.д.), с включением/выключением по нажатию.
- **6 настраиваемых виджетных экранов** — листаются свайпом влево/вправо от хаба. Каждая
  кнопка настраивается с телефона: текст, форма, размер, позиция в сетке, цвет (отдельно
  для состояний ВКЛ и ВЫКЛ) и действие (авто-переключение / запуск / включить / выключить).
- **Настройка с телефона** — в официальном приложении Zepp (Настройки приложения):
  подключение (URL HA + токен), обнаружение сущностей, переключатели локаций и сущностей,
  редактор виджетных экранов.

- **Material Design Icons** — тот же самый набор иконок, что использует Home Assistant:
  каждая строка в списках локаций показывает иконку домена, а каждой кнопке виджета можно
  выбрать одну из 70 иконок в редакторе настроек.
- **Работает офлайн / корректная деградация** — последние известные состояния кэшируются;
  при недоступности Home Assistant часы показывают кэшированные данные (с указанием возраста)
  вместо ошибки.

## Обновление и батарея

Состояния обновляются при каждом открытии приложения, а пока приложение открыто —
автоматически не чаще раза в 5 минут. Zepp OS не разрешает сторонним приложениям обращаться
к сети в фоне — это ограничение платформы, кэш покрывает паузы.

## Настройка

1. Home Assistant → ваш профиль пользователя → **Долгоживущие токены доступа** → создайте токен.
2. В приложении Zepp откройте **Настройки** приложения: укажите базовый URL HA
   (например `http://192.168.1.10:8123`) и токен, затем нажмите **Синхронизировать**.
3. Включите нужные на часах локации и сущности; при желании настройте виджетные экраны.
4. Откройте приложение на часах — состояния обновляются при каждом запуске.

## Сборка

```bash
npm ci
npm run build     # -> dist/*.zab (установочный пакет для часов)
npm run dev       # разработка в симуляторе
npm run preview   # установка на часы через QR-код (требует zeus login)
```

Готовые сборки: [GitHub Actions](https://github.com/Se7ven/Zepp-HA-Companion/actions) /
[Releases](https://github.com/Se7ven/Zepp-HA-Companion/releases) (теги `v*.*.*`).
